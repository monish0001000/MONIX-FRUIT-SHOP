DEFENSIVE CHECKLIST

How to remediate the patterns

  • Use textContent or safe templating instead of inserting untrusted values into innerHTML.
  • Treat localStorage and all browser-provided values as untrusted.
  • Enforce authentication and authorization on the server for every protected operation.
  • Use prepared statements or parameterized queries; never concatenate user input into SQL.
  • Keep secrets, tokens, personal data and production sessions out of training environments.

Retest each fix and preserve evidence of the result.
