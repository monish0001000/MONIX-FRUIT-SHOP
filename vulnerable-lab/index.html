DEFENSIVE CHECKLIST

How to fix the patterns

  • Use textContent or framework-safe templating instead of inserting untrusted strings into innerHTML.
  • Treat localStorage and all client-provided values as untrusted input.
  • Enforce authentication and authorization on the server for every protected operation.
  • Use prepared statements / parameterized queries; never concatenate user input into SQL.
  • Keep real secrets, tokens, personal data and production sessions out of the training lab.

A fix is complete only after a retest demonstrates the unsafe behavior is no longer possible.
